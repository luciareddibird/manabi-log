# まなびログ

サーバー学習を中心に、HTML・CSSの復習、短いコードの読解、学習ノートをひとつにまとめた学習アプリです。

## アプリを開く

GitHub Pages設定後に表示されるURLから利用できます。ログインは不要です。

## GitHub Pagesの設定

リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダーを **/(root)** にして保存してください。

## 記録について

進捗と学習ノートは利用中のブラウザーに保存されます。GitHubやほかの利用者へ送信されません。端末やURLが変わる場合は、旧アプリの「学習ノート → 記録を書き出す」で保管し、新アプリで読み込んでください。

BOHRとの自動同期やAI APIへの接続はありません。講座名・コマ数を参考にした個人用補助アプリで、復習問題は独自に作成したものです。公式教材の転載ではなく、各公式授業との詳細な対応は未確認です。

## ファイル

- `index.html`：画面の枠組み
- `style.css`：デザイン
- `app.js`：講座、復習問題、学習プラン、保存処理

ビルドは不要です。パソコンでは `index.html` をブラウザーで開いて使えます。
